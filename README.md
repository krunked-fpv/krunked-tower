# Krunked Tower

A 60 Hz deterministic, hand-inked 90s cartoon 2D kinetic speed-platformer built for Desktop, Xbox/Gamepad, Tesla Chromium, and Mobile Touch.

## Features
- **Hyper-Kinetic 60 Hz Platforming**: Mach 1–4 velocity ramp, instant Mach Drift turnaround boosts, slope surfing into vertical wall-climbing, grab-dash canceling, airborne piledrivers, uppercuts, charged Superjumps with shoulder-bash cancels, heavy bodyslams, 8-tick Taunt Parries, and 10-kill screen-clearing Super Taunts.
- **Two Full Campaigns + Tag-Team Stages**: Play as **Chef Peppo** or **The Static** (skateboard Mach run, wall bounce, drill crusher, instant Superjump), plus **Gusto & Chonks** tag-team segments.
- **5 Tower Floors, 19 Stages, 5 Multi-Phase Bosses & Bonus Modes**: Full progression across Lobby, Western Strip, Resort Deck, Neon Slum, Staff Penthouse, The Crumbling Spire finale, Secrets of the Tower, and Candy Panic — complete with 5 Caged Toppin Pals, 3 Secrets, Gerry's Treasure, Pillar Chronos, Krunk Time! escape countdowns, Lap 2 greed, Mega-Crust chaser, and P-Rank mastery.
- **Multi-Device Ready**: Keyboard & Mouse, plug-and-play Xbox/Standard Gamepads with granular deadzones, rumble, and dynamic HUD glyphs, plus **touch-activated translucent virtual controls** (with Mach Lock) that remain completely hidden until touched.
- **100% Standalone Built-In Art & Web Audio Synth**: Ships with original procedural 90s cartoon pixel art, WebGL2 shaders (palette swapper across 16 unlockable costumes, multi-hue afterimages, hit flash, panic vignette), Corner CRT TV HUD animations, and a 25+ track procedural Web Audio soundtrack, plus optional local Custom Pack loading.

## Quick Start
```bash
npm install
npm run dev
```
